# T10 — generacja według treści i przełączenie odbiorców

> Wykonanie: `superpowers:executing-plans`, testy RED→GREEN, niezależny review całej gałęzi.

Cel: zrealizować zaakceptowany T10 [#15](https://github.com/dlubom/Georeferencer/issues/15)
z [planu jakości](2026-10-24-jakosc-danych-i-ci.md), zachowując kontrakty T03–T09.

Architektura: rozszerzenie istniejącej publikacji T04 i odbioru T09. Każdy build
waliduje cały wybór; pełny build przyrostowy kopiuje poprawne wyniki do nowego
kompletnego przebiegu. Fingerprint obejmuje treść wejść, kod i środowisko.
Zakres Git opisuje kandydatów, nigdy nie zastępuje fingerprintu aktualności.
Tylko niepewność zakresu wymusza przeliczenie mimo zgodnego cache.
Jedna funkcja pakowania rozwiązuje current raz, wykonuje pełne QA wyników
i pakuje wyłącznie jawny manifest. Raporty i ZIP są poza przebiegiem.

Technologie: obecny Python/GDAL/Pillow/pyproj, przypięty `ci/Dockerfile` i lock;
bez nowych zależności i bez zmian źródeł/geometrii/wyjątków/historii.

## Decyzje wykonawcze

- Zachowujemy schemat manifestu v1 z wymaganym rozszerzeniem `content_version`
  dla nowych wyników. Dawny przebieg bez fingerprintu/środowiska jest nieaktualny.
- Cache odczytuje tylko raz rozwiązany `current`; wyniki są kopiowane, bez
  hardlinków i symlinków. Niekompletny/uszkodzony rekord jest regenerowany.
- `--all` i `--changed` tworzą pełny aktualny katalog; `--cave` pozostaje
  jawnym podzbiorem i nie może przejść bramki wydania całego katalogu.
- Domyślne wyniki i raporty trafiają do ignorowanego `build/`. Produkcyjny
  zapis computed/TFW do źródeł zostaje usunięty. Testy dawnego zapisu zastępujemy
  testami niemutowania i zgodności matematyki; orakle T02/T06 są niezmienione.
- Zmiana wspólnego rejestru/kodu/pinu/środowiska unieważnia konserwatywnie cały
  katalog. Brak lokalnego rejestru jest jawnym składnikiem fingerprintu.
- Pełna/płytka/niepewna historia Git skutkuje pełnym przeliczeniem. Lokalne
  wywołanie bez zakresu Git używa pełnego skanu treści i weryfikacji cache.
