```sh

  --candidate data/coordinate-source/source-v1.3.2.json --output /tmp/gps-impact.json

./scripts/build report --run-dir "$GPS_RUN" --require-results \
  --reports-dir /build/gps-v1.3.2-candidate/full-qa
./scripts/build package --mode manual --run-dir "$GPS_RUN" \
  --reports-dir /build/gps-v1.3.2-candidate/manual-qa \
  --archive /build/gps-v1.3.2-candidate/candidate.zip
./scripts/build accept --report /build/gps-v1.3.2-candidate/archive-acceptance.json \
  verify --archive /build/gps-v1.3.2-candidate/candidate.zip
```

Pakowanie wymaga czystego SHA PR, nie main. Wszystkie raporty i ZIP leżą
poza przebiegiem. `coordinate-source-v1.3.2-audit.py` wykonuje dodatkowy

`--run-dir`, `--qa`, `--revision` i `--output`. Uruchamia się w tym samym
