## Konieczne zmiany kontraktów i testów

Wycofanie zapisu do źródeł oznacza zmianę domyślnego miejsca wyników i API
produkcyjnego generatora. Smoke i testy modeli badają teraz jawne i domyślne
osobne wyjście. Dawny zapis porównawczy działa tylko na kopii danych w /tmp,
z zamrożonym generatorem T06 sprawdzonym **oryginalnym hashem** raportu T06.
Testy awarii wymagające GDAL używają force, aby cache nie ominął miejsca
kontrolowanej awarii. Nie osłabiono testów liczb, obrazu, półpiksela ani modeli.

ZIP zawiera manifest i trzy pliki na plan zamiast płaskiego globu TIFF.
Zachowuje proweniencję i nie pomija braków. Testy workflow sprawdzają wspólną
bramkę i przypięty wrapper zamiast dawnych poleceń apt/zip/copy.

`tests/host/` wykonuje prawdziwy Git i wrapper w bibliotece standardowej
hosta; kontener GDAL nie zawiera Git. `./scripts/check` obowiązkowo uruchamia
oba zestawy. Obliczenia, GDAL, historia i QA pozostają w tym samym przypiętym
kontenerze; żaden wcześniejszy test nie jest pomijany.
